## 一句话

> 把「每次重写提示词」变成「固定角色资产」——人设建一次，内容长期像你。

| 常见 AI 写作 | **主角** |
|--------------|----------|
| 空白聊天框碰运气 | **先建人设**，每次自动注入 |
| 假大空编事实 | **真实素材 / 日记** 再改写 |
| 用完即走 | **今日待办 · 连续记录 · 反馈** |

## 三大卖点

1. **人设优先** — 定位 / 语气 / 红线写进角色，矩阵不串味  
2. **真实输入改写** — 日记、图、视频、笔记 → 标题 / 正文 / 标签  
3. **为天天用设计** — 待办、连击、「表现不错」反馈闭环  

---

## 3 分钟上手

1. 打开 [zhujue-kappa.vercel.app](https://zhujue-kappa.vercel.app)  
2. 注册（显示名 + 邮箱 + 密码）  
3. **新建角色** → 记日记或上传素材 → **生成** → 复制发布  

建议在设置中配置 **自备模型 API Key**，生成更稳。
